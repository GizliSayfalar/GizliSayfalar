# E-Dergi yayınlama

Her sayı için:

`dergi/sayi-02/`

gibi yeni bir klasör oluştur.

- `index.html`: sayı giriş sayfası
- `articles/`: web üzerinde okunacak eserler
- `pdf/`: PDF dosyaları

Web sürümünü tercih ediyoruz; PDF ise alternatif format olarak tutulabilir.

Okuma ekranında:
- ilerleme çubuğu
- içindekiler
- yazı boyutu ayarı
- açık / sepya / koyu kâğıt
- mobil uyum
- dokunmatik sağ/sol kaydırma
- klavye Home/Escape desteği
bulunur.
