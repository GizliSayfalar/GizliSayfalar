GIZLI SAYFALAR — ACTIONS DÜZELTMESİ

1. Bu ZIP'i aç.
2. İçindeki .github klasörünü GitHub repository'sinin ana dizinine yükle.
3. GitHub > Settings > Pages > Source kısmını "GitHub Actions" yap.
4. Commit changes yap.
5. Actions > "Gizli Sayfalar — Build ve Deploy" çalışıp yeşil olduğunda site deploy edilir.

Bundan sonra yeni şiir/öykü:
icerik/siir/ veya icerik/oyku/ içine .md dosyası ekle -> Commit changes.

Akış:
Markdown -> HTML -> GitHub Pages otomatik deploy
